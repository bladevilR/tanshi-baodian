## ✨ 六大核心模块

### 1. 🥗 三倍碳水与生活化减脂系统 ([02-fat-loss-nutrition-system.md](./references/02-fat-loss-nutrition-system.md))
- **白板系数矩阵**：完整收录《三个月生活化减脂全攻略》中按性别与每周有效运动时长（`2~3h` / `4~5h` / `6~7h` / `8~9h`）匹配的碳水（`2.0~3.5 g/kg`）、蛋白质（`1.4~1.8 g/kg`）、脂肪（`0.8~1.2 g/kg`）计算矩阵。
- **生熟重换算与避坑铁律**：严格区分“营养素纯重”与“食材生/熟实重”，提供常见碳水、肉蛋奶与隐形油脂换算表。
- **7～10 天单变量复盘决策树**：结合周均体重、腰围、对比照、主项力量与睡眠排便状态，提供不掉秤、掉力量、饥饿或平台期的单变量调整处方。

### 2. 📅 凯圣王 × 谭成义三分化（PPL）与 1245 四分化高频计划 ([03-three-split-and-1245-program.md](./references/03-three-split-and-1245-program.md))
- **原版推/拉/腿（PPL）三分化**：完整收录联名三分化动作、组数、3 周次数递进表与 12 周周期化推进模板。
- **上班族黄金 1245 四分化高频计划**：针对固定周一、二、四、五（练二休一、练二休二）排期，将上肢拆分为**周一拉、周二推、周四下肢与髋底座、周五上肢高频补强（肩宽+胸背弱项+手臂刻度）**，精准踩中 48～72 小时肌肉蛋白合成窗口。
- **隔日腹部三件套 + 真空腹**：反向山羊挺身（含 4 种进阶变式）+ 绳索跪姿卷腹 + 悬垂举腿（骨盆后卷），配合日常真空腹改善肋骨外翻与胃凸。

### 3. 🔥 私教系列与独创“焚决”体系 ([04-private-coaching-and-fenjue.md](./references/04-private-coaching-and-fenjue.md))
- **五部位保姆级私教课**：腿部、肩部、胸部、背部、手臂的课前激活、动作轨迹与呼吸控制（如上斜卧推 45° 夹角触胸不弹、罗马尼亚硬拉正握从上往下启动与瓦氏呼吸）。
- **焚决系列精要**：焚决背部（肩胛持续下沉对抗 + 顶峰高压换气）、焚决肩后束（宽握小幅度满张力弹指）、保加利亚蹲双模式（直立偏股四 vs 前倾偏臀与后侧链）、坐姿腿屈伸三模式（标准/窄距外侧/宽距内侧）。
- **手臂意念-肌肉连接**：单臂绳索下压（身体向对侧微转预收紧雕琢三头刻度）、仰卧臂屈伸（斜上方推 2/3 行程增三头维度）、高低位绳索弯举（内旋攻肌峰 + 坐地慢离心攻维度）。

### 4. 🩺 生物力学痛点排查树 ([04-private-coaching-and-fenjue.md](./references/04-private-coaching-and-fenjue.md))
- 针对**卧推肩前侧痛/弹响**、**高位下拉斜方肌酸/背没感觉**、**深蹲硬拉下背酸痛/膝内扣**、**肋骨外翻/骨盆前倾**、**手臂训练无泵感**五大高频痛点，提供 `底层解剖诊断 → 课前泡沫轴松解与激活前菜 → 动作轨迹修正` 闭环处方。

### 5. 🧠 谭指导 6 大心智模型与科学边界 ([05-mindset-and-expression-dna.md](./references/05-mindset-and-expression-dna.md))
- 提炼**质量 > 剂量**、**频率 > 单次剂量**、**先开发地基再上负荷**、**主项严守 RPE 8（留 2 次余力）**、**同重量先填满次数再加重**、**单侧暴露盲区** 6 大心智模型、10 条决策启发式与“谭指导”角色扮演表达 DNA。
- 收录 2026 AGP Natural Pro 赛事档案及复合动作 vs 孤立动作的 RIR/RPE 差异化疲劳管理边界。

### 6. 🍱 82kg 上班族一周四练实战备餐模板与计算器 ([01-user-82kg-profile.md](./references/01-user-82kg-profile.md) & [macro_calc.py](./scripts/macro_calc.py))

## 🚀 快速安装与使用

### 1. 作为 AI Agent Skill 安装

将本仓库克隆到你的 Agent 技能目录即可自动生效：

```bash
# Claude Code
git clone https://github.com/bladevilR/tanshi-baodian.git ~/.claude/skills/tanchengyi-coach

# Codex
git clone https://github.com/bladevilR/tanshi-baodian.git ~/.codex/skills/tanchengyi-coach

# Antigravity / Gemini
git clone https://github.com/bladevilR/tanshi-baodian.git ~/.gemini/config/skills/tanchengyi-coach
```

### 2. 使用命令行营养计算器 (`scripts/macro_calc.py`)

```bash
# 按谭成义白板公式计算任意体重/性别/周运动时长的每日三大营养素目标：
python3 scripts/macro_calc.py --weight 75 --sex male --hours 6-7 --no-profile

# 计算 82kg 档案在周一（练背大消耗日）扣除固定基底、7-11能量碗、饭团和香蕉后的晚餐缺口与米饭肉量：
python3 scripts/macro_calc.py --day 周一 --preset 711_bowl --preset 711_onigiri --preset banana

# 手动输入今日额外已吃的宏量（碳水,蛋白质,脂肪）并折算剩余熟米饭与瘦肉克数：
python3 scripts/macro_calc.py --day 周三 --eaten "75,35,20"
```
